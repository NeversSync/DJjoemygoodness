# Starting points

Choose one in the toolbar, then press **Start**. This replaces the current animation (Undo brings it back).

- **Blank**: 13 solo lanes (one per motor), zero keys every 10 frames. Best for new ideas.
- **Attract**: the sculpture's signature show, 4 lockstep lanes.
- **Wave Motion**: a longer solo-lane wave (about 45 s).
- **Butterfly**: custom groups with mirrored (inverted) motors.

Every starting point passes physics, so any issue you see afterwards came from an edit.
