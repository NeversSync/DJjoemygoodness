# Save & load

Nothing is uploaded: files stay on your device until you email them.

- **Save JSON** writes `<name>.json`. Supported browsers ask where to save; others (such as iPad Safari) download it to *Files → Downloads*.
- **Load JSON** opens a file you saved earlier. It replaces the current animation (Undo brings it back).
- Files are capped at **9 MB** so they stay email-friendly. Typical shows are under 200 KB.
- Refreshing the page keeps your work for this tab. Closing the tab clears it, so save first.

## Settings in the file

- **Blend** (interpolate): on = smooth transitions between keys; off = jump and hold.
- **Machine %**: the speed Our Team will run it at on the sculpture. Physics always checks full speed.
