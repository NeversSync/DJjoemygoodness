# Keyboard shortcuts

- **Ctrl+Z / Ctrl+Y**: undo / redo
- **Ctrl+A**: select all keys
- **Ctrl+C / Ctrl+V**: copy / paste at the playhead
- **Ctrl+D**: duplicate the selection after itself
- **Ctrl+Shift+D**: mirror-duplicate (ping-pong)
- **Delete**: remove selected nodes on the Edit lane only
- **Alt+Delete**: remove selected keys for every lane
- **Space**: play / stop
- **← / →**: previous / next key
- **Ctrl+wheel** (⌘+wheel on Mac): zoom the Keyframe Graph toward the cursor
- **? or F1**: help

On a tablet (no keyboard), use the matching buttons:

- **Toolbar**: Undo / Redo (also beside Save / Load)
- **Keyframe Graph**: Undo, Redo, Select all, Add, Delete, Remove, Average, Copy, Paste, Dup, Mirror
- **Transport**: play, stop, previous / next key
